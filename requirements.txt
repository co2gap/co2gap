# This is not a full lockfile. It is a record of what was actually running when

# the kilograms, not the arithmetic around them.

#     Python 3.11 · numpy 2.5.1 · scipy 1.18.0
#
#   Mac (lab) — decomposition, aggregation and site build:
#     lab/run_decompose.py, lab/site_build.py -> data/decomposition_ecac/, site/
#     Python 3.11.5 · numpy 2.4.6 · scipy 1.17.1
#
# The two packages that matter for the published numbers — the fuel model and
# the data format — were identical on both.
